# bellabeat_data_analysis
Data analytics case study exploring Fitbit fitness tracker data using Python, Pandas, Jupyter Notebook, and Tableau.

## Questions

- What are the main trends in smart device usage?
- How do activity and sleep patterns vary among users?
- How could these insights help Bellabeat's marketing strategy?

## Tools

- Python
- Jupyter Notebook
- Pandas
- Tableau

## What I did

- Checked and cleaned the data
- Checked for missing values and duplicate records
- Converted date columns to datetime format
- Analyzed daily activity and sleep data
- Grouped users by activity level
- Calculated summary statistics
- Prepared summary data for visualization
- Created visualizations in Tableau

## Main findings

- The average number of steps was **6,547 per day**.
- Users recorded **10,000 or more steps on 27.8% of days**.
- **14 users** had low activity, **15** had moderate activity, and **6** had high activity.
- Average sedentary time was about **995 minutes per day**.
- Average sleep duration was about **7 hours per day**.
- **44.1% of recorded sleep days** had less than 7 hours of sleep.

## Recommendations

Based on my analysis:

1. **Encourage daily movement**  
   Set simple daily step goals and send reminders to less active users.

2. **Promote better sleep habits**  
   Provide simple sleep tips and reminders to help users maintain a regular sleep schedule.

3. **Create personalized daily goals**  
   Use activity and sleep data to give users simple daily goals based on their habits.
